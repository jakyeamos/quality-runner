## Goal

Make Quality Runner useful during implementation without weakening the
authoritative task boundary: fast checks should provide low-latency feedback,
while the final task check must prove that no new enforced finding was added
and that comparable coverage, evidence identity, and certified gates remain
valid.

## Execution Rules

- Preserve the existing `task start` baseline and rebaseline lineage.
- Keep `net_delta` informational; release eligibility is based on introduced
  enforced occurrences and explicit unknown/blocker predicates.
- Fast checks skip certified gates but retain the existing complete analysis
  and cache semantics; they must expose their provisional status and cannot
  return release-ready evidence. Deferring global analysis is a follow-up
  optimization because the current balanced coverage contract is partial.
- QR remains evidence and policy evaluation only; CI or branch protection owns
  the external release decision.
- Do not commit `.quality-runner/` generated artifacts.
