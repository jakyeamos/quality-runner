# Quality Runner system map

This is a proposal-stage system map. The repository's root Compass,
architecture context, evidence contracts, code, and receipts remain
authoritative.

## Load order

1. Read `CONTEXT.md` for the proposed audit, handoff, consumer, and certifier
   boundaries.
2. Read `_meta/schema.md` before adding cards.
3. Use `objects/_index.md` to choose a bounded noun slice.
4. Verify source citations before marking a card verified.

No `processes/` or `effects/` shelf exists yet.

## Authority

- `.project-compass/` owns product intent, child purpose, quiz answers, and
  alignment.
- This map owns only the proposed file-backed structure.
- Quality Runner remains an evidence orchestrator; it does not mutate target
  repositories, install dependencies, or commit remediation.
